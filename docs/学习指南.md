# PaiSmart 学习指南

> 派聪明 AI 知识库管理系统 - 从入门到精通

## 一、项目概述

PaiSmart (派聪明) 是一个企业级 AI 知识管理系统，基于 RAG (检索增强生成) 技术。系统采用 Spring Boot + Vue 3 前后端分离架构，集成 Elasticsearch、Kafka、MinIO 等中间件，实现智能文档处理和检索问答能力。

### 核心技术栈

| 层级 | 技术 |
|-----|------|
| 前端 | Vue 3 + TypeScript + Pinia + Vite |
| 后端 | Spring Boot + Spring Security + JWT + JPA |
| 搜索 | Elasticsearch 8.10.0 (KNN + BM25) |
| 消息 | Kafka 3.2.1 |
| 存储 | MySQL 8.0 + Redis 7.0.11 + MinIO 8.5.12 |
| AI | DeepSeek API + 通义千问 Embedding |

## 三、RAG 核心流程学习（2-3 周）

### 整体数据流

```
用户上传 → 分片存储 (MinIO) → 合并文件 → Kafka 异步处理 → 解析分块 → 向量化 → Elasticsearch 索引
                                                                    ↓
用户提问 ← WebSocket 流式响应 ← DeepSeek API ← 混合搜索 (KNN+BM25) ← 权限过滤
```

## 附录：核心概念解释

### RAG (Retrieval-Augmented Generation)

检索增强生成是一种结合检索和生成的 AI 技术：
1. **检索**：从知识库中检索与问题相关的文档
2. **增强**：将检索结果作为上下文添加到 Prompt 中
3. **生成**：LLM 基于上下文生成准确的回答

### KNN (K-Nearest Neighbors)

K 近邻算法在向量搜索中的应用：
- 将查询转换为向量
- 计算与知识库向量的相似度（余弦相似度）
- 返回最相似的 K 个文档

### BM25 (Best Matching 25)

经典的文本检索算法：
- 基于词频和逆文档频率计算相关性
- 对长文档有较好的归一化处理
- 与向量搜索互补，提高召回率
